# News Homepage

A responsive news homepage built with HTML and CSS as a practice project for improving CSS Grid, Flexbox, and responsive design skills.

## 🚀 What I Practiced

* CSS Grid
* Grid columns and rows
* Grid item positioning
* Flexbox
* Responsive layouts
* Media queries
* Mobile-first adjustments
* Navigation layout
* Card-based content sections

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome

## 📱 Responsive Design

The layout adapts to smaller screen sizes using CSS media queries. The desktop navigation is replaced with a menu icon on mobile, and the content changes from a multi-column Grid layout to a single-column layout.

## 🎯 Purpose

This project was created as a CSS Grid practice project to improve my ability to build complex webpage layouts and make them responsive.

## ✨ Features

* Responsive navigation
* News article section
* Featured article
* Trending content cards
* Responsive mobile layout
* CSS Grid-based page structure
* Font Awesome icons
